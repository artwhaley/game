# Ticket 05 — Action Block Browser

The Inspector has a Blocks tab with searchable block names, summaries, rename/delete commands, drag source behavior, and right-click insertion/save commands. The Add Action surface is labeled separately from authored rows and no longer includes the old search box.

Human gate: open the Blocks tab, create a block from a selected action or full sequence, rename it, delete it, and verify the operation remains in the current editor context. Acceptance is pending manual review.
